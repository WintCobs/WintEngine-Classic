#  WintEngine Classic v2.1.0

[RU] **WintEngine Classic** — это кастомный, ультра-легкий и независимый 3D-движок, разработанный для создания инди-проектов в оффлайн-режиме.
[EN] **WintEngine Classic** is a custom, ultra-lightweight, and independent 3D game engine built for offline indie game development.

---

## 🇷🇺 Ключевые особенности (Russian)

* 👑 **Максимальная оптимизация:** Стабильные 240+ FPS в разрешении почти 3К при нагрузках до 50 МИЛЛИОНОВ полигонов в сцене.
* 🌧️ **Погодный движок:** Динамический дождь, снег, туман и продвинутая система времени суток (`sky_time`) с процедурными кучевыми облаками.
* 📜 **Собственный скриптовый язык:** Интегрированная панель со своей системой событий `engine.on("start")` и автоматической проверкой синтаксиса кода.
* ⚙️ **Редактор ресурсов:** Удобные воксельные чертежи моделей по осям Y и Z, а также импорт/экспорт через JSON-массивы.
* 📦 **Низкий вес билда:** Полная автономность от интернета. Готовый скомпилированный исполняемый файл весит всего от 16.3 МБ до 20 МБ.

---

## 🇺🇸 Core Features (English)

* 👑 **Maximum Optimization:** Stable 240+ FPS in near-3K resolution under loads of up to 50 MILLION polygons per scene.
* 🌧️ **Weather Engine:** Dynamic rain, snow, fog, and an advanced time-of-day system (`sky_time`) with procedural cumulus clouds.
* 📜 **Custom Scripting Language:** Integrated panel featuring its own `engine.on("start")` event system and automatic code syntax checking.
* ⚙️ **Resource Editor:** Voxel model blueprints on Y and Z axes, and seamless JSON-based import/export.
* 📦 **Low Build Size:** Complete offline autonomy. The final compiled executable file is only 16.3 MB to 20 MB.
